# Kasper — HTML & CSS Second Project

A responsive agency-style one-page template (**Kasper**) built with **pure HTML5 and CSS3** — no frameworks, no JavaScript. Second practice project in a series of three.

## Sections

- Home / hero
- Services
- Portfolio
- About
- Pricing
- Contact

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (Flexbox / Grid, media queries)
- [Normalize.css](https://necolas.github.io/normalize.css/) for cross-browser defaults
- Font Awesome icons
- Google Fonts (Open Sans)

## Run it

No build step needed:

```bash
git clone https://github.com/Dr-Demon-M/Html_css_second_project.git
cd Html_css_second_project
```

Then open `index.html` in a browser — or serve it with any static server (e.g. VS Code **Live Server**).
